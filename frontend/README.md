# movie-recommendation
 
## Project setup
```
npm install
```
## Run Vue in Frontend directory
```
cd frontend
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Run Flask in Backend directory
```
cd backend
```

### Run Flask
```
py app.py
```
